# TheBrief

TheBrief — кроссплатформенный скилл для написания, редактирования и проверки русскоязычных финансовых, банковских и продуктовых текстов.

Он помогает:

- объяснять сложные финансовые понятия понятным языком;
- писать и редактировать Telegram-посты;
- готовить текст для клиентских и партнёрских презентаций;
- собирать продуктовые one-pager;
- улучшать текст без скрытого изменения смысла, цели и степени уверенности;
- отмечать недостающие и сомнительные факты, не подменяя редактуру выдуманным фактчекингом.

## Как устроен

- `SKILL.md` — точка входа и рабочий процесс.
- `references/methodology.md` — общая редакторская методика.
- `references/article-patterns.md` — паттерны, извлечённые из обучающего корпуса финансовых статей.
- `references/semantic-preservation.md` — правила сохранения смысла.
- `references/formats/` — отдельные требования к Telegram, презентациям и one-pager.
- `tests/scenarios.md` — поведенческие сценарии для проверки скилла.

Исходная книга, внутренний policy и полные тексты статей в репозиторий не включены.

## Использование в Agent Skills

Установите папку `thebrief` в каталог скиллов поддерживаемого агента и вызовите её явно:

```text
Используй $thebrief. Отредактируй текст, сохрани его смысл и продающую задачу. Сначала покажи готовую версию, затем объясни существенные изменения.
```

Для среды без установки Agent Skills используйте инструкцию из `adapters/generic-instructions.md` и добавьте папку `references` в знания проекта.

## Статус

Это первая рабочая версия. Следующая калибровка будет сделана на реальных текстах и замечаниях редактора.
