# TheBrief

Скилл для ИИ: пишет, редактирует и проверяет тексты о финансах по методике «Пиши, сокращай». Форматы: посты для Telegram-канала, слайды для клиентов и партнёров, one-pager о продукте, письма.

Что делает: сохраняет смысл и цель автора, убирает воду, канцелярит и ИИ-штампы, объясняет термины, отмечает недостающие факты и сразу предлагает вариант.

## Состав

- `skills/thebrief/` — сам скилл в формате Agent Skills (Claude, ChatGPT, Codex):
  - `SKILL.md` — ядро. Работает и без остальных файлов.
  - `references/` — форматы (Telegram, презентации, one-pager), каталог стоп-слов и ИИ-маркеров, приёмы объяснения финансов, словарь терминов, разобранные примеры.
  - `scripts/check_text.py` — проверка текста на стоп-слова, длину и ИИ-маркеры.
  - `agents/openai.yaml` — карточка для Codex.
- `platforms/chat-instructions.md` — инструкция для проектов ChatGPT и Claude, где скиллов нет.
- `platforms/CLAUDE.md` — фрагмент для Claude Code.
- `dist/thebrief.zip` — готовый пакет для загрузки.
- `dist/thebrief-full.md` — все правила одним файлом, для базы знаний проекта.
- `evals/evals.json` — 9 тестов с проверками.
- `scripts/build.py` — пересобирает `dist/` после правок.

## Установка

| Где | Как |
|---|---|
| Claude (сайт, приложение) | Включить выполнение кода в настройках. Затем Customize → Skills → «+» → Upload a skill → `dist/thebrief.zip` |
| ChatGPT Business, Enterprise, Edu | Plugins → Skills → Create → Upload → `dist/thebrief.zip` |
| ChatGPT Plus или Pro | Создать проект. В Instructions вставить `platforms/chat-instructions.md`, в Files загрузить `dist/thebrief-full.md` |
| Проект в Claude | Вставить ту же инструкцию и загрузить тот же файл. Или подключить скилл: в проектах он тоже работает |
| Claude Code | Скопировать `skills/thebrief` в `~/.claude/skills/thebrief`, вызов — `/thebrief` |
| Codex | Скопировать `skills/thebrief` в `~/.agents/skills/thebrief`, вызов — `$thebrief` |
| Custom GPT | Не подходит: OpenAI закрывает GPT. Создать новый можно до 26.10.2026, работать они перестанут 11.12.2026 |

## Примеры запросов

- «Отредактируй пост по скиллу thebrief: …»
- «Напиши пост для канала: ЦБ снизил ставку, что это значит для вкладов»
- «Сделай текст 6 слайдов для клиентов партнёра, условия: …»
- «Проверь по thebrief, подходит ли текст под наши рамки, не переписывай»

Ответ на редактуру устроен так:

1. Готовый текст.
2. Что изменено и почему.
3. Нужен факт — метка и предложенный вариант.
4. Проверьте.
5. Нужно ваше решение — только для правок, которые меняют смысл.

## Как проверяли

Старую и новую версию прогнали на 6 тестах, грейдер оценивал вслепую:

| Показатель | Старая | Новая |
|---|---|---|
| Выполнено проверок | 78% | 93% |
| Оценка грейдера, в среднем | 6,0 из 10 | 7,7 из 10 |
| 1-е место | в 1 тесте из 6 | в 5 тестах из 6 |

Ядро без справочников на более слабой модели тоже обошло старую версию.

Во втором круге доработаны:

- варианты к меткам фактов;
- запрет добавлять от себя оговорки и сравнения;
- режим проверки без переписывания;
- продающие заголовки.

Затем добавлены 3 новых теста: «только текст» с конфиденциальными данными, слайды по скудному брифу, деловое письмо.

## Источники и конфиденциальность

- Методика книги «Пиши, сокращай» (Ильяхов, Сарычева) пересказана своими словами. Текста книги в репозитории нет.
- В `references/formats/telegram.md` пересказан внутренний policy канала, поэтому репозиторий держите приватным.
- Из статей Т—Ж взяты приёмы, без цитат.
